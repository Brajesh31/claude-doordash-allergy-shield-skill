# Allergen Review Checklist

## Ingredient review
- [ ] Exact menu item and current menu version identified
- [ ] All listed ingredients reviewed
- [ ] Sauces, dressings, marinades, toppings, and garnishes considered
- [ ] Substitutions and optional add-ons checked
- [ ] Missing ingredient details recorded as unknown

## Cross-contact review
- [ ] Shared fryer or oil
- [ ] Shared grill, pan, oven, or prep surface
- [ ] Shared utensils, gloves, containers, or cutting boards
- [ ] Bulk bins, bakery cases, or shared serving equipment
- [ ] Packaging or handling after cooking

## Communication
- [ ] Allergen named explicitly
- [ ] Request asks for confirmation, not an unsupported guarantee
- [ ] Restaurant has a way to contact the customer if unable to accommodate
- [ ] User understands unknown information remains unknown

A menu description cannot establish kitchen practices. When severe allergy risk is involved, unresolved answers are a reason to avoid the item.
